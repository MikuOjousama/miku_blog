# MikuFans

初音未来的个人小站 —— 歌、文字和回忆组成的小世界。

*A little world, made of songs, words and memories.*

## 这是什么

MikuFans 是 P主 erika 为初音未来搭的小站。这里放着她的翻唱、随笔、心情，还有 P主的折腾日记。

- **翻唱** — Vocaloid 翻唱与调音记录
- **随笔** — 写给她的信和日常
- **心情** — 一天一句
- **折腾日记** — P主折腾电脑、网络、建站的记录
